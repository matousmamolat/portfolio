01

SpellBattle

  • Work in progress
  • Mobile game
  • Unity 6 · C#

A real-time 1v1 mobile duel I'm building solo in Unity 6 and C#. It starts from the core idea of Super Spell Heroes and builds its own systems and design on top of it. Two players draw paths across a board of elemental tiles, and every tile they match fuels the spells they throw at each other.

Three heroes are playable, each with a full set of attacks, shields and support spells. Heroes feel distinct even when they share an element, every spell hits a single target so fights stay tense and readable, and some shields hold hit after hit while others break on first use, so deciding when to block and when to attack really matters.

The biggest lesson so far: design systems that can grow. Stats and spell data are structured so that character progression can be added later without rewriting what already works.

06

Generative studies

  • 2026
  • Personal
  • JavaScript · Canvas API

Every grey wave on this site is drawn live in your browser by my own JavaScript. No photos, no videos. Each pixel's brightness comes from a sine wave nested inside another sine wave; random parameters give every visit a different image. Adding time to the formula makes it flow, and every few seconds each wave slowly morphs into a brand-new shape.

  • Secured web server Information Systems Security · 2026 My own Debian server at the university, running Matomo web analytics with login through LDAP. I configured Apache with HTTP/2 and TLS 1.3, added a full set of security headers, allowed SSH only with keys and fail2ban, kept LDAP reachable only from the server itself and set up automatic security updates. The result was grade A on securityheaders.com and A+ on SSL Labs.
  • Web tracking analysis Information and Communication Technologies · 2025 A study of how Novinky.cz, Alza.cz and CNN.com follow their visitors. Using a clean browser profile and Chrome DevTools, I recorded requests to third-party domains, cookies, localStorage and tracking triggered by scrolling or shopping, and backed every finding with HAR exports. Novinky.cz tracked the least, CNN.com by far the most.
