Generative studies

  • 2026
  • Personal
  • JavaScript · Canvas

Every grey wave on this site is drawn by my own code, not a stock photo. Each pixel's brightness comes from a sine wave nested inside another sine wave, with random parameters and film grain on top. Adding time to the formula makes it move — the loop on the home page repeats seamlessly because sine returns to where it started.
