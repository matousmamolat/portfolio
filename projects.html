05

Generative studies

  • 2026
  • Personal
  • JavaScript · Canvas API

Every grey wave on this site is drawn live in your browser by my own JavaScript — no photos, no videos. Each pixel's brightness comes from a sine wave nested inside another sine wave; a seed number picks the parameters, so every image is unique but always the same. Adding time to the formula makes it move, and the loop is seamless because sine returns to where it started.
